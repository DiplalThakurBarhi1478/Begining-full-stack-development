Prototypes in JS (Every object has prototype, an object)
---------------------------------------------
    A javascript object is an entity having state and behavior (properties and method)

    JS objects have a special property called Prototypes
    
    We can set prototype using __proto__

    Note: if object and prototype have same method then object's method will be used.

    Note: array is an object and it contains prototype.

Classes in JS (Constructor Method)
----------------------------------
    -> constructor method is automatically invoked by new 
    -> initializes object

Note we can initialized any variable at the time of creating constructor
    
    class myClass{
        constructor(brand, mileage){
            console.log("I am a constructor and I can initialize any variable");
            this.brand = brand;
            this.mileage = mileage;
        }
    }

    let obj = new myClass("toyota", 10);
